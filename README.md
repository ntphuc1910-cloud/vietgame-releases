# VietGame — Bộ cài Windows

Dịch phụ đề và menu game PS5 sang tiếng Việt theo thời gian thực, thuyết minh giọng Việt offline (VieNeu),
hiển thị phụ đề lên TV LG webOS.

**Tải về:** vào mục [Releases](../../releases/latest), tải `VietGame-Setup-<phiên bản>.exe` và chạy.
App tự báo và tự cập nhật khi có bản mới.

## Yêu cầu

- Windows 10/11 64-bit
- Máy PS5 cùng mạng LAN (Remote Play), tài khoản PSN
- Khóa API Google Gemini và/hoặc Groq của riêng bạn (nhập trong app)
- Không bắt buộc: TV LG webOS, card NVIDIA (để giọng đọc nhanh hơn)
